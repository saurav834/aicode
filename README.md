# AI CODES
## Repository Structure

| File | Experiment | Algorithm / Concept |
| :--- | :--- | :--- |
| `exp1_dfs_bfs.py` | Experiment 1 | Depth First Search (DFS) & Breadth First Search (BFS) |
| `exp2_astar.py` | Experiment 2 | A* (A-Star) Search Algorithm |
| `exp3_greedy_mst.py` | Experiment 3 | Greedy Search (Prim's Minimum Spanning Tree) |
| `exp4_n_queens.py` | Experiment 4 | Constraint Satisfaction Problem (N-Queens via Backtracking) |
| `exp5_chatbot.py` | Experiment 5 | Elementary Rule-Based Customer Interaction Chatbot |
| `exp6_expert_system.py` | Experiment 6 | Medical Diagnosis Expert System (Rule-Based Inference) |
| `exp7_minimax_tictactoe.py` | Experiment 7 | Game Playing Algorithm (Minimax for Tic-Tac-Toe) |

## How to Run

1. Clone this repository:
   ```bash
   git clone https://github.com/<your-username>/SPPU-TE-AI-Practicals-2024.git
   cd SPPU-TE-AI-Practicals-2024
   ```

2. Run any experiment using Python 3:
   ```bash
   python exp1_dfs_bfs.py
   ```
